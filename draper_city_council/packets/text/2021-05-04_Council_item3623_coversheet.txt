Re: Ordinance #1489, amending DCMC Title 2 regarding noticing requirements Comments: This city initiated application is a request for approval of a text amendment for the purpose of amending Title 2 of Draper City Municipal Code to address recent changes to Utah State code.
The 2021 Utah State Legislative Session passed Senate Bill 201, which removed the need to publish ordinance adoption notices and election notices in a newspaper. Draper City needs to amend the Draper City Municipal Code to follow the new requirements.  ATTACHMENTS: Description Upload Date Type Ordinance 1489, Title 2 4/29/2021 Cover Memo Request for Council Action 4/30/2021 Cover Memo
