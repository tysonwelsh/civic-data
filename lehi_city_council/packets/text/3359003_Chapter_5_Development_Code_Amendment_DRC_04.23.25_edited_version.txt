Narrative –Chapter 5 & Table 05.040-A Residential Zones Bulk and Intensity Development
Code Amendment

The Planning Division is proposing a Development Code Amendment to update sections of
Chapter 5 of the Development Code. Specifically, we are proposing a comprehensive update to
Chapter 5 and a subsequent update to the Bulk and Intensity Table to match.

The primary changes made with the comprehensive update are as follows:
   • Cleaning up and simplifying the text.
   • Creating a more specific purpose for each of the zones.
   • Removing outdated and no longer applicable information about the R- 2.5 zone.
   • Removing exceptions to bulk and intensity requirements for curvilinear street layouts or
       coving.
   • Removing stricter public notice procedures for permitted uses in the Public Facility zone.

We believe this will help clarify the interpretation of the Code.

Please contact the Planning Division if you have any questions.

Thank you,
