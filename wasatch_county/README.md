# wasatch_county

**A REGISTERED-ONLY entity** (`registry/entities.csv`, since 2026-07-20): Wasatch County is
registered so the hierarchy can carry **Park City's second within-county edge** — there is no
county build, no `db/`, no vote layer, and nothing federated into `gov.db`.

`campaign_finance/` (2026-08-01) is this entity's **first and only dataset**: 111 county-office
campaign-finance filings across the 2010–2026 cycles, retained verbatim with per-file
provenance. Start with `campaign_finance/RECON.md`, then `AVAILABILITY.md` and `CLAUDE.md`.

Adding this module does **not** make Wasatch a built entity — the registry status is unchanged.
