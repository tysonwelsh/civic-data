            3. APPROVE AND ADOPT AN ORDINANCE AMENDING UTAH COUNTY CODE SECTION 9-1-10
            RELATED TO FIRE PREVENTION AND PROTECTION.
            - Kirk Bertelsen, Utah County Fire Inspector –


            KIRK BERTELSEN, UTAH COUNTY FIRE INSPECTOR - THIS IS JUST PUT OUR CODE IN
            ALIGNMENT WITH THE NEW STATE CODE WITH YURTS AND SO WE’RE JUST EXEMPTING
            THEM FROM OUR CODE AS LONG AS THEY MEET THE STATE DEFINITION FOR REMOTE
            YURTS.

            IN OUR ORDINANCE, PART ‘A’ SAYS, ‘THIS CHAPTER SHALL NOT PROHIBIT THE USE OF
            TEMPORARY TENTS OR MEMBRANE STRUCTURES THAT ARE USED SOLELY FOR
            RECREATIONAL CAMPING’.

            PART ‘B’ SAYS, ‘THIS CHAPTER SHALL NOT PROHIBIT THE USE OF REMOTE YURTS AS
            DEFINED IN 15A-1-204 12B, UTAH CODE’. TEMPORARY BY THE BUILDING CODE AND THE FIRE
            CODE MEANS 6 MONTHS.

            ‘A’ AND ‘B’ ARE ADDRESSING TWO DIFFERENT DEFINED TERMS. A TENT AND A MEMBRANE
            STRUCTURE ARE DEFINED DIFFERENTLY THAN A REMOTE YURT. THE STATE IS THE ONE
            THAT MADE THE REMOTE YURT DEFINITION. ACCORDING TO THE BUILDING CODE AND
            FIRE CODE A YURT WOULD BE CONSIDERED A MEMBRANE STRUCTURE, BUT THE STATE
            CHANGED THAT. THEIR REMOTE YURT HAS A DIFFERENT DEFINITION.

            ROBERT MOORE, COUNTY ATTORNEY OFFICE – THE STATE CREATED THE ’REMOTE YURT’
            AT THE LAST LEGISLATURE. IT’S TOTALLY DIFFERENT THAN ‘A’. ‘A’ WAS ALREADY
            ADOPTED ON APRIL 30, 2019. ‘B’ IS THE REMOTE YURT THAT’S DISCUSSED TODAY.

            THE STATE OF UTAH THROUGH THE DIVISION OF ALCOHOLIC BEVERAGE COMMISSION
            CONTROL REGULATES 99.9% OF ALCOHOLIC BEVERAGES IN THE STATE OF UTAH. WE HAVE
            2 DIFFERENT TYPES OF USES:
                • ON-PREMISE CONSUMPTION (RESTAURANTS/BARS) WHICH ARE REGULATED BY THE
                   STATE. THEY ALLOW LOCAL AUTHORITY FOR CONSENT AND LICENSING. BEFORE A
                   NEW ESTABLISHMENT WOULD COME INTO UTAH COUNTY, THE COMMISSION WOULD
                   HAVE TO APPROVE A CONSENT FORM FOR THEM TO ACTUALLY BE LICENSED TO
                   SERVE ALCOHOL.
                • OFF-PREMISE CONSUMPTION (CONVENIENCE/GROCERY STORE – BUY TO TAKE HOME
                   TO CONSUME). IN THE PAST, THE COUNTY HAS REGULATED THIS. THE STATE NOW
                   REQUIRES LICENSES THROUGH THE STATE, BUT AS FAR AS LOCAL AUTHORITY, WE
                   GRANT CONSENT AND WE HAVE THE ABILITY TO LIMIT LOCATION, HOURS AND GIVE
                   A LICENSE.
