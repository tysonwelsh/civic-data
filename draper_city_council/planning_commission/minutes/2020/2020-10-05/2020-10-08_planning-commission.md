      Action)
      On the request of Draper City for a Text Amendment in order to modify Draper City
      Municipal Code Sections 17-5-030, 9-27-150, 9-32-030, 9-3-040, 9-5-090, 9-19-090, 17-
      2-020, 17-3-020, 9-22-040, 17-1-040, and 17-4-020 in order to modify development
      access points requirements and reduce or eliminate the requirement for paper submissions
      with applications. Application TEXTMAP-1039-2020. Staff contact is Jennifer
      Jastremsky, 801-576-6328, jennifer.jastremsky@draper.ut.us.

      Ms. Jastremsky reported that the text amendments covered development access points
      and paperless applications. The City posted a notice of intent to modify the code in
      March 2020. This notice of intent listed changes pertaining to the interconnectivity,
      access points and road connections of multiple-family projects. There was concern that
      their code was inadequate for referring developers to what access points were required.
      Since March, the question had been how do insure proper access for developments. The
      solution is to clarify in the code how many access points are required and what is an
      access point. She showed a slide with how the code was written. She noted “possible”
      items reviewed for change:

      Single Family
      • One access point is required for up to thirty units
      • Widen street width standards and private right-of-way to insure a 20-foot minimum
         width in asphalt
      • Private right-of-way can serve up to 20 single-family units (she noted this would not
         change from current code)

      Two family and townhome unit developments

       • Two access points are required for 31 units or more

       Multi-family unit developments other than town home unit dwellings
       • One access point is required for projects with up to 100 dwelling units
       • Two access points are required for projects with 101 or more dwelling units

       She noted that the text would include a definition that defined what an access point is.

       Changes to the code will include the definition of an access point into the definitions
       section.
       • Access point: A two-way roadway access into a subdivision or development that
