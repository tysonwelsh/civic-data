## 5. Elections

`alta_races.csv` = 3 races (2021 Council At-Large, 2021 Mayor, 2023 Council At-Large).

- **Internally consistent (2023, the only unsuppressed race):** candidate votes Morgan 66 +
  Schilling 51 + Davis 42 = **159 = total_first_choice_votes**; winner_pct 41.51 = 66/159 ✅;
  by-candidate pcts sum to 100 (rounding).
- **At-large multi-seat margin handled correctly:** 2-seat, 3-candidate race; `margin_votes=9`
  = last winning seat (Schilling 51) − first loser (Davis 42), `margin_pct=5.66` = 9/159 ✅.
  Both winners (Morgan, Schilling) carried in `alta_results_by_candidate.csv`; the
  single-column `winner`/`runner_up` in races.csv reads top-seat + first-loser, consistent.
- **2021 suppressed race handled honestly:** county SOVC suppressed tallies (privacy);
  blank votes + `note` documenting external winners (Byrne, Anctil) and that Margaret E.
  Bourke did not win. by-candidate encodes both winners + loser.

### alta_canyon_excluded_ok: **YES**
The county source (`salt_lake_county/elections/slco_municipal_results_long.csv`) **does**
contain the unrelated recreation-district contests — `ALTA CANYON REC BOARD MEMBER` (2007),
`ALTA CANYON REC SERVICE DIST` (2009), `Alta Canyon Rec Service` (2011), `ALTA CANYON REC`
(2013). **None appear** in the Alta repo's raw (`municipal_results_long_alta.csv`), in
`alta_races.csv`, or in `cities.db.election_race` (grep "canyon" = empty). The ingest
correctly took only `ALTA COUNCIL` / `ALTA MAYOR` / `TOWN OF ALTA` contests. Clean disambiguation.

### Pending-2025 gap (honest)
No 2025 municipal election in `alta_races.csv`, the Alta raw, or the county long file — **yet
a 2025 election demonstrably occurred**: the 2026-01-14 minutes reference *"Craig Heimark's
election to the town council (from role as Treasurer)"* and the geo tool's current council
now seats Heimark. This is a **genuine pending acquisition gap** (county 2025 SOVC not yet
published/acquired), not an error — but it should be logged in TODO.md. Separately, pre-2019
Alta results (2007–2017) exist in the retained raw but are not promoted to races.csv,
consistent with the repo's 2019+ election floor — worth a one-line note in the election CLAUDE.

## 6. Ranked fix list

1. **[WARN — fix or document] Named roll-call undercapture (~6 council motions).** When a
   member's vote token wraps to the next line with a dangling em-dash (`Councilmember Byrne —
   .\nyes`), or the block uses a non-colon anchor (`ROLL CALL VOTE;`), or narrative phrasing
   (`X, Y … voted "Aye"`), the parser drops that member. Confirmed: **2021-05-12** (4 lost),
   **2025-01-08** (Byrne), **2025-12-09** (Anctil+Morgan); high-confidence single-vote drops:
   **2024-11-13**, **2025-03-12**, **2024-06-20**. Impact: named attribution incomplete +
   derived `APPROVED (N-0)` string understated (e.g. 2025-12-09 stored 3-0, truly 5-0).
   **Never** flips an outcome (all affected are unanimous approvals), **never** fabricates —
   error is honest-direction (under-count). Fix: normalize line-wraps + accept `;` anchor +
   handle the `"…voted 'Aye'"` list grammar, then re-extract the affected files.
2. **[Honest gap — log] 2025 municipal election** results absent (election occurred; Heimark
   won). Add to TODO.md as a county-SOVC acquisition item.
3. **[Cosmetic doc drift] `meeting_minutes/CLAUDE.md`** claims "165 named / 315 tally-only"
   motions and "9 distinct voters"; actual split is **168 named / 312 tally-only** (voters,
   contested=13, RECORDED=21 all correct). Refresh the two stale numbers.
4. **[Minor] PC seconder occasionally dropped** — 2022-06-02 m1 (Wyssen Towers CUP) source
   says *"Mr. Abraham seconded"* but seconder is blank. Same attribution-miss class as #1.
5. **[Minor doc] Election CLAUDE** — note that pre-2019 raw (2007–2017) is retained but not
   promoted (2019+ floor).

- **PC all tally-only unanimous** — source ceiling (PC prints no roll call), not extraction loss.
