Regular Action Items 
#2 Aspen Springs Storage Conditional Use Permit 
Zetterquist reviewed the staff report for the Aspen Springs Storage Conditional Use Permit and is 
recommending a continuance of up to 90 days due to the project qualifying as an Urban Development of 
Smithfield’s future annexation area.  State Code requires that the City be notified and have up to 90 days 
to comment.  
Christensen motioned to continue the Aspen Springs Storage Conditional Use Permit up to 90 days; 
Rigby seconded; Passed 4, 0. 
05:37:00 
#3 Discussion: 2024 Code Amendment Priorities 
Staff and Commissioners discussed possibly amending minor subdivisions for a quicker review and 
approval process, flag lots ordinance, updating the zoning clearance process, detached ADUs, Civil Code 
Update for code enforcement, road way design for primitive trail heads, sensitive lands, conditional use 
permits, roadway cross-sections, state code changes, riparian zones, updating density standards/lot 
coverage, development standards/long range visioning, general plan review, campground/RVs on 
property, and resort development standards. 
06:12:00 Adjourned
