3.   Public Hearing and possible action regarding a Final Subdivision Plat for a 
proposed three (3) lot subdivision; 4450 N 1000 E, Oakley; CANR-1-2; Timothy & 
Melissa Evans, applicants. – Sean Lewis, County Planner 
 
Chair Clyde stated there was a lot of public comment on this application. This application 
was filed under the prior ordinance where this property had the benefit of the Highway 
Corridor Zoning, so this property qualifies under the Zone, which would make it difficult to 
deny this application.

Planner Lewis stated there was an issue with processing the public noticing for the Evans 
subdivision. Attorney Strachan explained that this application is quirky in that it straddles 
the time in which changes were being made to Chapter 3 and Chapter 4 of the Code. The 
application appears to meet minimum zoning requirements under the old Chapter 3. 
Because the application was submitted prior to those changes, the property is vested under 
the old code. There are concerns about this application going through the correct process. 
The proposal is for a subdivision within an existing subdivision and may need to go 
through a plat amendment process. Noticing was for a new subdivision, not an existing one. 
Under the current Chapter 4 of the Code, there is a process for re-subdividing, which would 
require an amendment to the subdivision plat as a seven-lot subdivision, which would 
require the MPD (Master Plan Development) process. It would be best to table this 
application to the next meeting to allow Staff to determine the best process. 
Commissioner Sonntag asked if there is an issue with noticing then is this application still 
vested under the old code. Attorney Strachan answered that if noticing was for an 
amendment to an old subdivision, then some people may not think it concerns them and 
did not come to the meeting tonight. There may be some other type of approval process 
required for this application. 
Chair Clyde stated there is a question of being able to increase density through a plat 
amendment. Planner Lewis answered that Code states that a plat amendment that results 
in a re-subdivision should go through a subdivision process, so there is no concern about 
the increase in density because the code allows it. Attorney Strachan stated the old plat is 
essentially being changed and should be noticed as an amendment to the existing plat.

The Public Hearing was opened. 
There were three emails entered into record that were provided to the Planning 
Commission. 
Tim Evans owns the parcel under discussion and stated there has been public notice and 
asked for clarification for the problem with noticing. Clarification was provided by Chair 
Clyde. If there was a legal challenge concerning the noticing, then the process for this 
application would have to start over. Staff will work to make sure the application is not 
open to challenges by following the process all the way through.  
Katherine Scott asked if there was a moratorium for applications during code changes. 
Planner Lewis answered there was never a moratorium for subdivision applications. The 
temporary ordinance that is in place is for the ten-acre split provision and the agricultural 
protection provision. This application is not under that provision in any way and would not 
be under a temporary zoning ordinance. There has never been a moratorium that would 
restrict the application for a subdivision. This application fits under the provisions for 
zoning under both the old and new zoning code. All criteria have been met. The issue is 
with process.

4.   Public hearing and possible action regarding a Final Subdivision Plat for a 
proposed two (2) lot subdivision; 740 East Chalk Creek Road, Coalville; NS-410-B; 
Margo Marsh, applicant. – Sean Lewis, County Planner  
 
Planner Lewis shared the background. The application is for a two-lot subdivision on a 
11.33-acre parcel in the AG5 zone. This parcel is eligible for two lots according to Chapter 2 
of the Code. The wastewater system was approved by the Eastern Summit County Special 
Service District and by the County Manager. Water will come from the Cluff Ward Water 
Company. Staff recommends approval of the two lots. There was clarification shown for the 
right of way and the location of the lots. 
 
The Public Hearing was opened. No public comment was made, and the Public Hearing was 
closed. 
 
Commissioner Hanson asked if there is a concern about the flood plain, with the lot being 
close to the creek. Planner Lewis answered that the applicant must comply at the time of 
the building permit. The subdivision has to be approved to have a conforming parcel. There 
are areas that are buildable on this parcel that will comply with setbacks. The flood plain 
comes into effect when a house is built. Drawing lines for the subdivision does not 
necessarily cause issues with the flood plains. 
Commissioner Hanson asked if Engineering is concerned about egress onto Chalk Creek 
Road. Planner Lewis answered that the egress was not brought up as part of the review, 
but he will check with Engineering about flood plain and access before the Director makes 
the final decision on this application.

5.  Public hearing and possible action regarding a Final Subdivision Plat for a 
proposed two (2) lot subdivision; 3106 E Highway 35, Kamas; CD-2222; DeLoy Bisel, 
applicant. – Sean Lewis, County Planner  
 
Planner Lewis shared the background. The application was made at the time of the 
temporary ordinance for the ten-acre split. Layered zoning was shown depicting old and 
new zoning. The temporary zoning ordinance states that a lot must be entirely within the 
agricultural protection zone to be eligible for the ten-acre split. There is a portion of the lot 
that was within the Highway Corridor Zone. There are two houses that exist on the 
property that were built in the 1940s. The applicant successfully petitioned the County 
Council to allow the two existing houses to be sold separately and grant a special exception 
that grants two units of density on this property, that allows the application to be made to 
subdivide this property. The subdivision would not grant any more density than what has 
already been established. The subdivision would just draw a dividing line to allow one 
house to be sold separately from the other. The County Council requested building 
envelopes be defined to protect the Provo River, which was done on the plat map. 
Everything else complies with Code. There is a shared driveway for both homes, with an 
access agreement in place. 
DeLoy Bisel, the applicant stated that the size of the small lot was increased to the one-
acre minimum to accommodate the easement and the recommendation of the Health

1. Discussion of a possible rezone of Lots 3 & 4 of the Red Onion Subdivision in 
Wanship; ROS-4. -Ray Milliner, Principal Planner 
 
Planner Milliner shared the background. The applicant, Sheldon Smith, is asking for a 
rezone of the property. At the previous work session there was a discussion about the 
development plan, which has now been created and submitted. Staff is asking for input 
from the Planning Commission for the development plan. Is the plan sufficient? Are the 
proposed uses appropriate for the site? Based on the input from the Planning Commission, 
a public hearing will be scheduled. 
Chair Clyde stated the ordinance requires a development plan for a rezone. The 
Commission seems inclined to go with commercial zoning because the property is not well-
suited for residential use due to the power line running through the middle and the
