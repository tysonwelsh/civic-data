The first issue was if a development agreement (DA) could be attached to the 
application.  Staff reviewed the Code to answer this question.  The Code indicates that a 
DA can be attached to any development proposal; however there are a couple of issues.  
Generally, DAs are attached to a SPA.  All of the criteria are written specifically for a
