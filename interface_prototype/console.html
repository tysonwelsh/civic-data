Run SQL

One read-only SELECT or WITH. The executor injects a LIMIT, caps rows and bytes, times out at 15s, and refuses everything that isn't a read — try DROP TABLE motion.

Try: nephi motion count most divided councils sum cf_filing (trap) cross-tier provenance (trap) MPO votes (trap) DROP (rejected) multi-statement (rejected)

Full-text search

FTS5 across the corpora, returning passages and resolved paths — the tier-dependent prefix is applied server-side. Counts are matching documents, one row per file. Click a path to open it in the reader.

Grep the repository

The layer FTS does not index. Search finds what governments published; this finds what the repository says about its own coverage, methods and known gaps — CLAUDE.md, TODO.md, LEADS.md, COVERAGE.md, each dataset's index.csv manifest. Scope it with a path and it returns in milliseconds; a repo-wide sweep may hit its deadline and say so.

Try: nephi tally-only unrecovered minutes honest zero open DEBT items

Resolve an entity

Turns a journalist's phrasing into slugs — with the ambiguity kept. "Salt Lake" must come back as both the city and the county; silently picking one is the likeliest wrong answer in the whole system.

Try: Salt Lake Park City Juab west valley Kanab

Coverage

What exists, what is deferred by design, and where the floors are. A (no vote layer) row is an honest property of a db-less county, not a gap to be filled.

Try: nephi washington_county wfrc_mpo ut_state everything

Read a document

Opens primary text — minutes, statutes, advisory opinions — so a claim can be checked against the source rather than a paraphrase. Confined to the repo root; try /etc/passwd.

Schema

DDL on demand — the agent pulls this rather than carrying a schema blurb in its prompt, because a copied blurb goes stale within two builds.

Try: caveat motion, motion_std v_contested_all list everything
