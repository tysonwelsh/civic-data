Example Motion
I move the Planning Commission recommend approval of the Code Text Amendment to
Title 18 removing language addressing Commercial Uses in each zone (18.65, 18.70,
18.75, 18.80, 18.85, and 18.100) and defer to the Table of Commercial Uses as presented.

Background

This is a public hearing for a proposed Code Text Amendment to adjust Riverton City’s
Commercial Uses in Title 18 – Land Development Code. This proposal does not make
substantial changes to current policy or practice. The goal of this proposal is to make it easier for
customers, city officials, and city staff to identify land uses in the city’s commercial zones. To
achieve this goal staff identified these objectives:
    1- Place all commercial zones in one Table of Uses, and
    2- Eliminate references to commercial uses in each commercial zone description (18.65,
       18.70, 18.75, 18.80, 18.85, and 18.100).

At the Planning Commission meeting on December 8, 2022, commissioners recommended that
City Council consolidate two table of uses by adding unique uses from the PPC Table of Uses to
the existing “Table of Commercial Uses”. City Council approved this change on January 17, 2023.



Explanation of Proposed Changes

Commercial zones are not consistently described, and some discrepancies have been found
between zone descriptions and the Table of Commercial Uses. Staff is proposing to eliminate
references to commercial uses in each commercial zone description and thus eliminate any
discrepancies in the code by deferring to the updated Table of Commercial Uses. This change
would affect commercial zone descriptions 18.65, 18.70, 18.80, 18.85, and 18.100 by removing
