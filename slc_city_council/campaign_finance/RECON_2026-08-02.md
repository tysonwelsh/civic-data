# SLC campaign finance — adversarial channel hunt, 2026-08-02

**Purpose.** The 2026-07-05 determination in `AVAILABILITY.md` — *"the dotnet.slcgov.com
portal is the one real source; no PDFs exist anywhere; the state tree doesn't carry SLC
city candidates"* — was a single-session hypothesis. This addendum re-tests it
channel-by-channel. Precedent: the juab "no public posting" determination was falsified by
a second look.

**Result: the negative was PARTLY WRONG.** Two of its three claims are falsified.

---

## Headline findings

1. **A PDF era EXISTS and was recovered.** Salt Lake City's Recorder published
   per-candidate campaign-finance disclosure PDFs at
   `slcgov.com/recorder/fin_disc/pdfs/<Candidate_Name>.pdf`, indexed by
   `recorder/fin_disc/feb_fin_disc.htm` ("**February 15th 2003 Candidate Financial
   Disclosures**"). These are **full filings** — summary, balance summary, **itemized
   contributions with donor names/amounts/dates, and itemized expenditures**. The index
   lists **11 candidates**; **8 recovered** (see below). This falsifies
   *"No PDF/document filings anywhere (portal is data-only)"*.

2. **A PREDECESSOR SYSTEM existed, 2003–2019.** Before the Angular SPA there was the
   "Salt Lake City Corporation — Candidate Finance Reporting System", an ASP.NET WebForms
   app at `dotnet.slcgov.com/ManagementServices/CandidateReporting/` (also served from the
   now-DNS-dead `apps1.slcgov.com`). Its `candidate_search.aspx` year dropdown enumerates
   election years **2003, 2005, 2007, 2009, 2011, 2013, 2015, 2017, 2019**. This falsifies
   *"No pre-portal (2007–2017) filings online"* as a statement about what the city ever
   published — those cycles WERE online, in a system now broken.

3. **The live 503 "maintenance" page is NOT empty — it carries live data.** The 35,503-byte
   page served for every dynamic request under `CampaignFinance_Public` embeds a
   **"Campaign Information" table: 38 candidates × (name, election year, office, balance)**,
   "Balance as of April 2026", for the open 2027 and 2029 SLC campaigns. Captured. The
   July session treated this response as a pure outage page.

4. **The outage is APP-SPECIFIC, not a dead server.** The sibling candidate-filing app
   `Attorneys/CampaignFinance_Candidate/api/CampaignFinanceAPI/*` answers **HTTP 401**
   (`{"Message":"Authorization has been denied for this request."}`) with live ASP.NET
   headers, while the public app's identical API path returns **503**. The database is
   demonstrably alive (it renders the balance table on the 503 page). This reframes the
   blocker: not "the data is gone" but "the public read surface is switched off".

## Corrected source determination

| 2026-07-05 claim | Status after 2026-08-02 |
|---|---|
| "SLC self-hosts; the dotnet portal is the one real source" | **Still true for 2019+ itemized data**, but incomplete: SLC also ran a 2003–2019 predecessor system and, earlier, published PDFs. |
| "No PDF/document filings anywhere (portal is data-only)" | **FALSE.** 8 recovered 2003 filings prove a document era. The claim was true only of the *current* SPA. |
| "No pre-portal (2007–2017) filings online" | **FALSE as stated.** Those cycles were online in `CandidateReporting` (year dropdown 2003–2019). What is true is that **no capture of their result pages survives** — the app was POST-only and is now HTTP 500. |
| "SLC files nothing to disclosures.utah.gov" | See parallel-channel results. |
| "Live API genuinely down" | **True, and now better characterised**: app-specific 503 while the sibling candidate app is up (401) and the DB is live (it renders the balance table). |

**Bottom line for the coordinator:** the itemized 2019–2025 layer still requires the live
public API (or the city). But the negative "nothing exists anywhere" is dead: a 2003
document tranche is in hand, and the 2005–2019 cycles are known to have been published in
a system whose files still sit on the city's IIS box (`D:\IISRoot\dotnet.slcgov.com\
managementservices\candidatereporting\`, per the live 500 error) — a GRAMA-shaped ask, not
a scraping problem.

### Channel 4 — disclosures.utah.gov / municipal.utah.gov  →  **CONFIRMED NEGATIVE, earned**

The prior "no" survives, and is now evidence-backed rather than assumed.

- Recursive crawl of `/Municipal/salt lake`: **90 folders, 667 file links; 667/667
  downloaded**; 407 image-only files **OCR'd** (tesseract, 200 dpi).
- **Classified by the office line inside each form**, per the GOTCHAS label-lies rule —
  in-form jurisdiction census: Cottonwood Heights 69 · Midvale 69 · Herriman 60 ·
  West Jordan 56 · Murray 47 · Riverton 43 · Taylorsville 36 · Millcreek 35 · Bluffdale 23 ·
  South Jordan 23 · Holladay 16 · Draper 15 · West Bountiful 14 · South Salt Lake 9 ·
  **Salt Lake City 0**. The 9 apparent "SLC" hits are all **South** Salt Lake.
- **The residence-town trap was hunted specifically.** The two flat folders with no city
  subfolders — `2009 Primary` (61 files) and `2011 Municipal` (60), both SLC election
  years and the highest-risk hiding places — were read **file by file**: zero SLC.
  SLC-specific marker sweep over all 667: `Meeker|Trishman` (SLC recorders) 0 ·
  `Salt Lake City Corp` 0 · `451 S State` 0 · `slcgov|slc.gov` 0 · SLC+Council/District 0.
- The one file sitting in an SLC-named folder is **not an SLC filing**:
  `salt lake_2013 Municipal_Salt Lake City / Financial Campaign Report - Sweat.pdf` —
  candidate Corey Dee Sweat, addressed **"TO: Heidi Voordeckers – City Recorder/Auditor"**
  (**West Bountiful**'s recorder), "District Office: NA" (SLC seats are districted); he
  appears in no SLCo canvass 2007–2025. Textbook label-lie: the folder records his
  **mailing city**.
- **No pre-2009 folder exists at all** — 2003/2005/2007 are absent from the state system.
  (Existence discriminator validated: nonexistent → a 63-byte
  `Path: \\172.16.120.206\Municipal\salt lake\2007 does not exist.`; exists-but-empty →
  an ~11.3 kB page. The negatives are distinguishable, not guessed.)
- State search UI (working endpoint `/Search/PublicSearch/SearchEntities?term=`, control
  passed): 27 SLC names queried. Every SLC figure present appears **only as a state
  legislative registration**. One SLC-adjacent positive — the *Erin J Mendenhall Leadership
  Fund* PAC (entity 1415339) — is a **nil record**: "No Reports Have Been Filed for 2019";
  its Final Report affirms no contributions and no expenditures.
- **The state disclaims SLC in its own tree:** `salt lake_2023` links "Salt Lake City →
  dotnet.slcgov.com/…/CampaignFinance_Public"; `salt lake_2025` links
  "Salt Lake City (Updated) → slc.gov/attorney/list-of-declared-candidates/".
- Statutory reason, from the Lt. Governor's own site: **Utah Code §10-3-208** — municipal
  candidates file with their **municipal clerk/recorder**.

*Honest residual:* 152 of 667 carry no explicit in-form jurisdiction line (mostly 2013 West
Valley, 2023 Brighton, OCR-degraded 2009/2011). Their non-SLC classification rests on folder
label + filename + the zero-hit result on all five SLC markers, not on a read office line.
That is the ceiling of this sweep.
