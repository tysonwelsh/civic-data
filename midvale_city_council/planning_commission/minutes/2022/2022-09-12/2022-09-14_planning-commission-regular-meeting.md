   2. Amendments to Section 17.7.11 of the Midvale City Municipal Code to (1) modify
      provisions for neon signs and (2) modify landscaping requirements for parking lots.

        Midvale City proposes amendments to the Main Street Form-Based Code (MS-FBC) to
        harmonize the code with current best practice and allow limited usage of neon elements
        within signage on Main Street.

        The landscaping section of the code requires improvements to the interiors of surface
        parking lots, and it has become apparent that innovative development patterns of mixed-
        use developments create surface parking lots with building or roof overhangs that make
        landscaping impracticable in certain situations. The code language has been adjusted to
        accommodate for this type of case.

        The amended code language in the signage section allows limited usage of “neon signs”
        if the project location is on Main Street within the MS-FBC area and is associated with a
        historic structure, or a parcel that used to host a historic structure. The amendment, if
        approved, will facilitate redevelopment in an authentic manner because neon signage
        was a part of many historic main streets throughout northern America.

        Public notice has been sent to affected entities as required in Section 17-3-9 of the
        Midvale Municipal Code. At the time of this writing no public comment has been
        received.

        Staff recommends approval.

                                               ***

APPLICANT:

Mr. Knobloch, representing Midvale City Planning Department, is explaining the purpose for the
code amendment. Neon signs on a historic main street were popular in the past but need to
maintain a limit to new signage. The proposal is to allow neon signs solely on historic buildings
or where an old neon sign once was or replacing a non-functional pre-existing neon sign.

The second part of this amendment is to control unusual development practices. Building
overhangs make it difficult to uphold the required landscaping for new developments. It will
address this issue and remove the requirement in these cases.

Commissioner Erickson requests the definition of “historic” that Midvale will be using to base
this code amendment. Certain code does address…

Mr. Wilcox clarifies that Midvale City Code does provide a definition for both “historic” and
“historic building”. The historic building, structure, site, and or object means any building,
structure, site, and or object that demonstrates any historic significance as set forth… and
references the form base code. The previous definition of historic means anything with interest
or value to the heritage, background, or cultural character of Midvale.

PUBLIC HEARINGS

    5. Amendment to the Midvale City General Plan regarding Moderate Income
       Housing.

        The city proposes an amendment to the housing section of the General Plan 2016. The
        amendment includes 3 phases for a moderate-income housing element, six moderate
        income housing strategies, and a five-year implementation plan. This moderate-income
        housing element is designed to meet current and future housing needs those households
        whose income falls on or below 80% of the area median income (AMI).

        Midvale City requests this amendment to be in compliance with Utah State Code 10-9a-
        403 and 17-27a-403.

        Public notice has been sent to affected entities as required in 17-3-9 of the Municipal
        Code. No comments have been received as of the writing of this report.

        Staff recommends approval.


PLANNING AND ZONING COMMISSION SEPTEMBER 14, 2022
                                              ***
APPLICANT:

Meggie Troili, RDA Project Manager for Midvale City, is proposing an amendment to the
General Plan based on updates made to the Utah State Code. The previous changes to the
General Plan were made in 2019 in a very similar fashion. In 2019 there were an excess of
strategies implemented into our plan and much was accomplished for Moderate Income Housing.

The new requirements of Utah State Code require Midvale to choose at least four new strategies
and provide a station area plan regarding the fixed guideway public transit station. We have also
chosen to include an extra strategy to take priority to UDOT funding opportunities. In total, we
will be selecting six new strategies to add to the General Plan. These strategies will be added to a
five-year implementation plan.

Phase 1 is to complete the updates to the General Plan by October 1, 2022. Phase 2 is to collect
and analyze more current data between now and the end of the fiscal year to refine the Moderate-
Income Implementation plan. Phase 3 is to submit annual progress reports for the next five years
while carrying out the new plan.

The six strategies have been selected carefully by the RDA, Planning Department, and
Community Development Department. The implementation plan is flexible and ready to be
updated according to data collected throughout the fiscal year.

The deed restriction on the properties would keep the units affordable for a designated amount of
time, usually 15-20 years. With the support of the RDA, it is required to keep these units within
the range to maintain funding. The definition of affordable is not determined by Midvale but by
the State of Utah. Utah does have the power to determine what affordable means, not the
developer.
