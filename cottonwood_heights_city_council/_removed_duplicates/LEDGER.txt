_removed_duplicates/ — the deliberate-removal ledger
====================================================

Every *.md file in this directory is a minutes document that was INGESTED but then
deliberately removed from the canonical layer because it duplicated another document
already in the index. `fetch_new.py::removal_ledger()` reads the BASENAMES here and
refuses to re-add any harvest candidate whose target basename matches — so a routine
`python3 fetch_new.py --ingest` can never resurrect one of these.

The files are kept (never deleted) as the audit trail of what was removed and why.

Deliberately NOT a .md file: the ledger is keyed by `*.md` basenames, so notes must
carry a different extension.
