Work Session (4:36 P.M.)
1.
Work session to get input on proposed engineering code amendments to titles 7, 9, 10,11,12 to establish a clear, unified set of technical standards. Steve Dennis, Summit County Engineering Department. (4:36 P.M.)
Steve Dennis,
Engineer
, provided information to the Commission and sought input and direction to set clear and consistent standards for the Engineering Code to be applied Countywide.
Commissioners provided feedback and asked detailed questions to which Steve Dennis, Mike Kendell and Patrick Putt responded. Engineering will return to the Commission with recommendations to be approved and forwarded to the County Council.
Attachment:
Basin Staff Report_Engineering Code_8-8-2023 Steve Dennis.pdf
Commissioners discussed minutes to be approved as well as minutes procedures. (5:33 P.M.)
Commission Items (5:42 P.M.)
Commissioner Hubler provided an update on the Silver Creek DRC.
Commission Chair Carmichael asked Director Putt for an update on the Outlets at Park City. Director Putt responded. Commissioner Cooke asked a follow up question of Director Putt.
Director Items (5:49 P.M.)
Director Putt reviewed the calendar for the next SBPC meetings.
