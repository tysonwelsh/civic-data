TOWN OF ALTA
ORDINANCE # 2026-0-11
AN ORDINANCE ADOPTING THE OFFICIAL ALTA ZONING MAP TO REFLECT
PREVIOUS ZONE AMENDMENTS
WHEREAS, Alta Town Code (ATC) 10-6-2 references the zoning map on file with the
town clerk;
WHEREAS, ATC 10-6D-1 (B) identifies Subzones A, B and C Within The Base Facilities
Zone which was adopted by Ordinance 2014-O-5, identified the subzones by property but did not
include a map of the subzones.
WHEREAS, the Town desires to have the Official Zoning Map reflect the subzones
NOW THEREFORE, BE IT ORDAINED BY THE ALTA TOWN COUNCIL AS FOLLOWS:
Section 1: Zoning Map ._ The official zoning map is adopted to update the map to identify
Subzones A, B and C as attached hereto.
Section 2: Effective Date. This ordinance shall go into effect after publication and posting as
required by Utah Code Title 10, Chapter 3
