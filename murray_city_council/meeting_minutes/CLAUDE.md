# meeting_minutes/ — Murray City Council vote pipeline

## What's here
- `minutes/<year>/<week-monday>/<date>_<slug>.md` — **170** City Council-body
  minutes, 2020-01 → 2026-06. Council meets **Tuesday**; the folder is keyed on that week's
  Monday (budget-committee/workshop meetings on other weekdays still bucket to their week's
  Monday). Indexed in `minutes_index.csv` (8-col standard). `source` = `civicplus` (132 files,
  CivicPlus ArchiveCenter `Archive/ViewFile/Item/<ADID>`, `Archive.aspx?AMID=31`) or **`pmn`**
  (38 files — 18 = the 2023 Tyler-TMM-lost regular meetings promoted 2026-07-16; **20 = the
  budget/workshop/CoW/town-hall/special council-body meetings promoted 2026-07-17 from PMN
  crosscheck leads** (slugs `budget-finance-committee`, `city-council-workshop`,
  `committee-of-the-whole`, `city-council-town-hall`, `city-council-special-meeting`,
  `city-council-walking-tour`); all born-digital, identity-verified; `source_url` = PMN
  `files/<id>.pdf`). `format` = `pdf-text` except **`ocr` for the 1 file recovered from an
  image-only scan** (2022-06-21, Tesseract, 2026-07-11).
- `raw/<date>_<slug>.pdf` — the retained source PDFs (never modified; raw-retention rule);
  the 18 promoted files keep their pmn_backfill basenames (`council_<date>_<pmn_file_id>.pdf`,
  sha256-traceable to `../pmn_backfill/raw/_fetch_log.jsonl`).
- `minutes_unrecovered.csv` — meetings that **exist but whose minutes were never recovered**.
  **Header-only since 2026-07-16**: the 18-row 2023 TMM gap fully resolved — 17 recovered +
  promoted, and **2023-07-11 was CANCELLED** (official PMN cancellation notice retained in
  `../pmn_backfill/`; a non-meeting is not an unrecovered gap). A net-new **2023-08-21
  Special Meeting** (joint with Millcreek, Murray North Station — discussion only, zero
  motions) was also promoted.
- `extract_votes.py` — the PURE deterministic parser (no LLM, no network; resumable).
- `votes/<year>/<week>/<date>_*.json` — one structured JSON per meeting (the resumable
  intermediate; `all_votes.csv` is rebuilt from these).
- `votes/_validation_report.txt` — integrity checks, per-year roster, tally mismatches,
  contested-vote list (regenerated by `validate_votes.py`).
- `all_votes.csv` — long format, **one row per member-vote** (or one placeholder row per
  tally-only motion), schema:
  `date,year,title,body,motion_no,motion,motion_type,result,mover,seconder,member,vote,source`.

## Run
```
python3 extract_votes.py     # writes votes/*.json then rebuilds all_votes.csv + roster.csv
python3 validate_votes.py    # writes votes/_validation_report.txt
```
`all_votes.csv` is valid RFC-4180 (motion text contains commas/quotes — read it with a real
CSV parser, NOT `awk -F,`). `extract_votes.py` skips meetings whose JSON already exists; pass
`--force` (or delete the stale JSON) to reprocess a rebuilt/recovered markdown file.

## Vote grammar — NAMED roll calls (Murray prints the full assenting side)
Unlike South Jordan/Sandy (dissenter-only narrative tally), Murray's clerk prints a **full
per-name roll call** on most motions, so the winning majority IS named. The deterministic
parser (`extract_votes.py`) handles both eras:

- **A) PROSE roll call (2020–2023 dominant):**
  `"Council roll call vote: Ayes: Councilmember Martinez, Councilmember Cotter, …
   Nays: None  Abstentions: None  Motion passed 5-0"` — each named Aye/Nay/Abstain → a row.
  2023 lists full names (`"Ayes: Rosalba Dominguez, Diane Turner, …"`) — the resolver handles
  both. Wrapped Ayes lists split across page-break footers are flattened before parsing.
- **B) TABULAR roll call (2024–2026 dominant):** `"Council Roll Call Vote: Mr. Hock  Aye  /
   Ms. Cotter  Aye  / …  Motion passed: 5-0"` — one member per line.
- **C) VOICE-VOTE tally-only:** `'Voice vote taken, all "ayes." Approved 5-0'` → **one
  placeholder row, blank member/vote** (`names_recorded:false`). The X Ayes are never guessed
  (61 such motions — a source style, not a missing extraction).
- **D) NOMINATIONS:** prose-confirm nominations parse as a normal named roll call; a
  candidate-selection roll call (members voting for a PERSON, e.g. `"Philip Markham wins 3-2"`)
  is recorded **tally-only** (result verbatim), since the values are names, not Aye/Nay.
- **E) DIED:** `"The motion was not seconded."` / `"MOTION FAILED: There was no second"` →
  recorded with no members.
- **F) CoW-style tally (2024/2026, added 2026-07-16):** `"Mr. Hock moved to approve, and
  Mr. Pickett seconded the motion. All in favor 4-0."` → tally-only (no names printed).
- **G) DEFERRED roll (2023-06-27 only):** the clerk printed `"SECOND MOTION"`, then the
  third motion + its roll, then `"ROLL CALL FOR SECOND MOTION … Motion passes 3-2"` — the
  parser matches a labeled deferred block to its ordinal-labeled intro instead of dropping it.

`motion_type` uses the fixed 12-category taxonomy (land-use checked first); `result` and the
numeric tally are **verbatim as printed**. Normalized outcome/tallies/type live **alongside**
in `motions_std.csv` (per the cardinal rules — verbatim is never overwritten).

## Council composition / the Mayor does NOT vote
Council–mayor (executive-mayor) form: **5 district councilmembers (D1–D5, no at-large)** +
a separately-elected **Mayor** who presides but **casts no council vote** (max ordinary tally
= 5, never 6). The Mayor is excluded from the voting roster; only the five district surnames
map to a vote (county/other-city officials named in the narrative never do).

**Roster drift to watch** (the observed roster has 13 members across 2020–2026):
- **Brett Hales** — District-5 councilmember **2020–2021** (190 real votes), then **Mayor
  2022+** (0 council votes). "Councilmember Hales" and "Mayor Hales" are the **same person**;
  his 2020–2021 rows are legitimate. He was re-elected Mayor in 2025.
- **Dominguez (D3)** leaves Dec 2024 → **Bullen** via the 2025 special; the 2023 appointees
  (Hrechkosy / Markham / Rodgers / Goodman) were later replaced. Surnames resolve to full
  names through the fixed canon in `extract_votes.py` (which also folds OCR/clerk typos).

## Don't

- Don't read a 6th Council voter as valid (the Mayor never votes; max roll = 5).
- Don't re-add 2023-07-11 as a meeting — it was CANCELLED (proven non-meeting, not a gap).
